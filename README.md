# SabziU Telegram Bot — V1

ربات تلگرام اولیه برند سبزی یو (@Sabziu_bot).

## امکانات نسخه اول
- /start
- منوی اصلی
- فروشگاه
- سبد خرید
- سفارش‌های من
- یو کارت
- حساب کاربری
- پشتیبانی

این نسخه اسکلت اولیه است و هنوز به WooCommerce / SabziU.ir متصل نشده است.

## اجرای محلی

Python 3.10+ نصب کنید.

```bash
pip install -r requirements.txt
```

متغیر محیطی زیر را تنظیم کنید:

```text
TELEGRAM_BOT_TOKEN=توکن_ربات
```

سپس:

```bash
python bot.py
```

## امنیت
توکن ربات را در کد، GitHub، فایل عمومی یا چت منتشر نکنید.
در سرویس ابری، Token را به‌عنوان Environment Variable / Secret ذخیره کنید.
